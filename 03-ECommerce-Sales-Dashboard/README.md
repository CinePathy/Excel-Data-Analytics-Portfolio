An interactive **E-Commerce Sales Dashboard built using Microsoft Excel** to analyze sales performance, profitability, product categories, sub-categories, and geographical sales performance.

# 📌 Project Overview

The E-Commerce Sales Dashboard provides a consolidated view of business performance using sales, profit, quantity, order, and profit-margin KPIs.

The dashboard allows users to interactively analyze the business using slicers for:

* Year
* Region
* Category
* State

The project combines **data cleaning, PivotTable analysis, KPI development, data visualization, and dashboard design** into one complete analytical solution.

# ▶️ How to Use

1. Download the Excel workbook.
2. Open the `.xlsx` file using Microsoft Excel.
3. Navigate to the **Dashboard** sheet.
4. Use the slicers to filter the dashboard.
5. Explore the charts and KPI cards.
6. Review the supporting analysis sheets.
7. Examine the data-preparation workflow.

Microsoft Excel is recommended for the best experience because PivotTables, slicers, and dashboard interactions may not work exactly the same way in other spreadsheet applications.
