
# 🛒 Super Store Sales Dashboard

An interactive **Super Store Sales Dashboard built using Microsoft Excel** to analyze sales performance, profitability, customer segments, regions, monthly trends, and product categories.

The project transforms raw sales data into meaningful business insights using **PivotTables, PivotCharts, KPIs, and dashboard visualizations**.

The goal of this project is to analyze Super Store sales data and create an interactive dashboard that provides a clear overview of business performance.

The dashboard focuses on:

* Customer segment analysis
* Regional sales
* Monthly sales trends
* Category-wise sales
* Key performance indicators

## 📑 Workbook Structure

The Excel workbook contains the following sheets:

### 1. Data

Contains the complete sales dataset used for the analysis.

### 2. Segment vs Sales

Analyzes total sales across different customer segments:

* Consumer
* Corporate
* Home Office

### 3. Region vs Sales

Analyzes sales performance across:

* Central
* East
* South
* West

### 4. Month vs Sales

Analyzes sales performance month by month to identify seasonal trends and high-performing periods.

### 5. Category vs Sales

Compares sales across:

* Furniture
* Office Supplies
* Technology

### 6. KPI

Contains the main business performance indicators.

### 7. Dashboard

The final consolidated dashboard containing KPIs and visualizations.

## 📅 Monthly Sales

The dashboard analyzes sales performance across all months.

The highest sales are observed in:

* November — approximately **$352.67K**
* December — approximately **$330.22K**
* September — approximately **$308.88K**

This provides a clear view of seasonal sales patterns.
