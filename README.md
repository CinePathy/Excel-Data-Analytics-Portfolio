
# 📊 Excel Data Analytics Portfolio

Welcome to my **Excel Data Analytics Portfolio**.

This repository contains a collection of practical **Microsoft Excel data analytics and dashboard projects** created to demonstrate my skills in data cleaning, data analysis, KPI development, PivotTables, PivotCharts, data visualization, and interactive dashboard design.

The projects cover different business scenarios such as **sales analysis, profitability analysis, customer purchasing behaviour, product analysis, and geographical analysis**.

---
